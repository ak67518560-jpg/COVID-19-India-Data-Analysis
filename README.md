
# COVID-19 India Data Analysis

## Project Overview
This project analyzes COVID-19 data in India using Python,
Pandas, Matplotlib, Seaborn and Plotly.

## Datasets
1. covid_19_india.csv
2. covid_vaccine_statewise.csv
3. StatewiseTestingDetails.csv

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Project Analysis
- Data Loading and Cleaning
- Missing Values Analysis
- COVID-19 Confirmed Cases
- State-wise Death Analysis
- Recovery Rate Analysis
- Vaccination Analysis
- First Dose vs Second Dose
- COVID-19 Testing Analysis
- Interactive Dashboard

## Key Findings
- Maharashtra recorded the highest confirmed cases.
- Maharashtra recorded the highest deaths.
- Uttar Pradesh recorded the highest vaccination doses.
- Uttar Pradesh recorded the highest testing samples.

## How to Run
1. Clone or download this repository.
2. Install required libraries:
   pip install pandas numpy matplotlib seaborn plotly
3. Open the Jupyter Notebook.
4. Run the notebook cells.

## Conclusion
This project demonstrates how Python and data
visualization tools can be used to analyze COVID-19
trends, vaccination and testing data across India.

Note: Findings are based on the historical datasets
used in this project, not current COVID-19 statistics.
